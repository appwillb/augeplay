🗄️ Arquitetura e Modelagem do Banco de Dados Relacional (PostgreSQL)
users & profiles Entidade Central
• id: UUID PRIMARY KEY
• email, password_hash, role: VARCHAR
• user_type: ENUM (musician, client, band, composer)
• base_cache: NUMERIC(10,2), rating_avg: FLOAT
• lat, lng: DOUBLE PRECISION, geohash: VARCHAR(12)
instruments_riders Riders & Mídia
• id: UUID PRIMARY KEY, user_id: FK
• instrument_name: VARCHAR(60), exp_years: INT
• stage_rider: JSONB (pedais, amps, in-ear)
• sample_audio_urls: JSONB ARRAY
• is_primary: BOOLEAN, updated_at: TIMESTAMP
works_compositions Obras & Direitos
• id: UUID PRIMARY KEY, composer_id: FK
• title: VARCHAR, genre: VARCHAR, bpm: INT
• lyrics_text: TEXT, audio_guide_url: TEXT
• isrc_code: VARCHAR(12), iswc_code: VARCHAR(11)
• sha256_hash: CHAR(64), timestamped_at: TIMESTAMP
dsp_distributions 460+ Plataformas
• id: UUID PRIMARY KEY, work_id: FK
• dsp_network: VARCHAR (spotify, apple, tiktok...)
• release_upc: VARCHAR(13), live_url: TEXT
• delivery_status: ENUM (queued, sent, live, error)
• payload_metadata: JSONB, synced_at: TIMESTAMP
royalties_splits Split Sheet / Lucros
• id: UUID PRIMARY KEY, work_id: FK
• recipient_user_id: FK, role: VARCHAR(40)
• share_percentage: NUMERIC(5,2) (ex: 50.00%)
• ecad_cae_ipi: VARCHAR(20), bank_acc_id: FK
• contract_signature: TEXT, signed_at: TIMESTAMP
gigs_contracts_calls Acordos & WebRTC
• id: UUID PRIMARY KEY, contractor_id: FK, musician_id: FK
• event_date: TIMESTAMP, agreed_cache: NUMERIC(10,2)
• escrow_status: ENUM (reserved, released, refunded)
• webrtc_room_id: VARCHAR(64), call_log: JSONB
• terms_signed: BOOLEAN, completed_at: TIMESTAMP

⚡ Excelência Técnica: Arquitetura, Segurança e Escalabilidade
• Latência Mínima em Vídeo: Arquitetura WebRTC com servidores de retransmissão TURN geo-distribuídos garantem chamada estável mesmo em redes 4G instáveis.
• Transcodificação de Áudio: Pipeline assíncrono para processamento de faixas sem perda de qualidade (lossless FLAC/WAV e MP3 320kbps otimizado).
• Segurança e Anti-Vazamento: Assinatura digital temporária de URLs de streaming para impedir ripagem e downloads não autorizados de obras inéditas.
🛡️ Alta Disponibilidade, Escalabilidade e Integridade de Dados
• Cluster PostgreSQL Otimizado: Índices GiST geoespaciais e particionamento de tabelas para consultas no radar em menos de 15ms.
• Conexões Concorrentes: Serviços conteinerizados com orquestração Docker e balanceamento de carga Nginx para alta concorrência.
• Conformidade Fonográfica DDEX: Mapeamento compatível com os padrões de metadados das distribuidoras mundiais de fonogramas.
